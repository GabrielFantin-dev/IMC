# 🧠 O que é o IMC?

O Índice de Massa Corporal (IMC) é calculado através da seguinte fórmula:

IMC = peso / (altura × altura)

Neste programa, o usuário informa sua altura e seu peso,
e o Java realiza o cálculo automaticamente.
